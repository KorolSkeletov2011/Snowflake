# Snowflake — Koch Curve Visualizer

Небольшое desktop-приложение на C++ и Qt Widgets, которое пошагово строит снежинку Коха. Фрактал начинается с равностороннего треугольника, а каждая следующая итерация заменяет один отрезок четырьмя.

Отрисовка выполняется через `QGraphicsScene`, а управление — клавишами окна приложения.

## Возможности

- переход к следующей итерации снежинки Коха;
- возврат к предыдущей итерации;
- увеличение и уменьшение масштаба;
- хранение уже построенных уровней для быстрого шага назад;
- ограничение глубины построения десятью итерациями.

## Требования

- Qt 5 или Qt 6 с модулем Widgets;
- qmake;
- компилятор с поддержкой C++17;
- GNU-совместимый заголовок `bits/stdc++.h`.

## Сборка и запуск

### Qt Creator

1. Откройте `Snowflake/Snowflake.pro`.
2. Выберите Desktop Kit с установленным Qt.
3. Соберите и запустите проект.

### Командная строка

```bash
cd Snowflake
qmake Snowflake.pro
make -j
./Snowflake
```

В зависимости от установленной версии Qt команда может называться `qmake6`. На Windows с MinGW обычно используется `mingw32-make`. На macOS результат сборки может быть создан как `Snowflake.app`.

## Управление

Окно должно находиться в фокусе, чтобы получать нажатия клавиш.

| Клавиша | Действие |
|---|---|
| `N` | Построить следующую итерацию. |
| `D` | Вернуться к предыдущей итерации. |
| `+` или `=` | Увеличить масштаб на 5%. |
| `-` | Уменьшить масштаб на 5%. |

## Алгоритм

Начальное состояние состоит из трёх сторон равностороннего треугольника. Для каждого отрезка `A → B` вычисляются точки на одной и двух третях длины, а средняя треть заменяется двумя сторонами нового равностороннего выступа:

```text
A -------- B

A --- P1
        \
         P3
        /
      P2 --- B
```

После одной итерации каждый исходный отрезок превращается в четыре. Поэтому на уровне `k` сцена содержит:

```text
3 × 4^k
```

отрезков. Время построения и потребление памяти также растут экспоненциально.

## Структура проекта

```text
README.md
Snowflake/
├── Snowflake.pro     qmake-проект
├── main.cpp          точка входа Qt-приложения
├── mainwindow.h      состояние окна и обработчик клавиш
├── mainwindow.cpp    генерация фрактала и отрисовка
└── mainwindow.ui     форма с QGraphicsView
```

Основные функции алгоритма:

- `dos(...)` разбивает один отрезок на четыре;
- `step()` создаёт следующий уровень для всех текущих отрезков;
- `keyPressEvent(...)` переключает уровни и управляет масштабом.

## Текущий статус и ограничения

- на больших уровнях количество графических элементов быстро становится очень большим: десятая итерация содержит более трёх миллионов отрезков;
- интерфейс не показывает номер текущего уровня и не содержит экранной подсказки по клавишам;
- размеры сцены и исходные координаты зафиксированы в коде;
- экспорт изображения отсутствует;
- тестов нет;
- `bits/stdc++.h` не является стандартным заголовком C++ и может помешать сборке на MSVC или стандартном Apple Clang.
